# Manual de despliegue (borrador)

1. Clonar el repositorio.
2. Copiar `.env.example` a `.env` y completar valores.
3. Crear la base de datos y ejecutar `/database/migrations`.
4. Instalar dependencias de `backend` y `frontend`.
5. Iniciar backend y frontend.

> Los comandos exactos se definirán al elegir el stack tecnológico.
