# Requisitos de la línea base

## Funcionales
- RF-01 Autenticación y roles de usuario.
- RF-02 Gestión de menú (platos y categorías).
- RF-03 Registro y seguimiento de pedidos.
- RF-04 Reservas por fecha y hora.
- RF-05 Cierre de caja y facturación.
- RF-06 Reportes de ventas diarios.

## No funcionales
- RNF-01 Aplicación web responsiva.
- RNF-02 Contraseñas cifradas y rutas protegidas por rol.
- RNF-03 Código documentado y versionado en Git.
